# 🛒 Pixel Perfect Ecommerce

Modern eCommerce web application built with **React**, **Tailwind CSS**, and **Razorpay integration** for seamless online payments.

---

## 🚀 Live Demo
👉 https://pixel-perfect-ecommerce-hi1uzhkhx.vercel.app/

---

## ✨ Features

- 🛍️ Beautiful and pixel-perfect UI
- ⚡ Fast and responsive design
- 💳 Secure checkout with Razorpay
- 🔄 Smooth loading and transitions
- 📱 Fully responsive (mobile + desktop)
- 🧩 Modular and reusable components

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Payments:** Razorpay API
- **State Management:** React Hooks
